{# Canonical flash + client-notification toast. ONE source of truth for flash rendering across the app. Renders a single reusable slide-in pill (border-[5px] rounded-full + PNG icon), decodes the icon before showing so it never flashes the wrong icon, and drains `get_flashed_messages()` at the bottom so EVERY page that includes this partial consumes the session flash queue on load. That consumption is the whole point: without it, a flash queued by a redirect (session expired, "entity not found", read-only write, CSRF) survives in the session and pops up later on some unrelated page — the "stale toast" bug. Client code can also raise a toast directly via the exposed helpers (showSuccessToast / showErrorToast / showFlashNotification / showToast / ...). Every helper is installed with a `window.X = window.X || ...` guard so a page that already defines its own richer version (e.g. the report / dashboard slider pages) is never clobbered — include this BEFORE the page's own script. #}
